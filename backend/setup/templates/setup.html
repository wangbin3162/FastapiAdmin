🚀 FastapiAdmin 初始化向导

一处填写，保存后同步回写后端、Docker、Web 与小程序的 env 配置。不建库、不迁移，首次启动后端会自动完成。

⚙️ 运行环境
决定写入 backend/env/.env.{dev,prod} 哪一份，并同步前端与 Docker 的环境标识。 切换环境会重新加载该环境已有配置，未保存的修改会丢失。
dev 开启 DEBUG；prod 关闭 DEBUG
生产建议 INFO 及以上
0.0.0.0 监听所有网卡，localhost 仅本机
前端代理与 WebSocket 地址会按此端口生成
🗄️ 数据库
默认 PostgreSQL。数据库需要事先创建（SQLite 除外），向导只测试连接，不会建库或改表。
PostgreSQL 驱动需 uv sync --extra postgres
数据库不存在时请先手动创建
Docker 容器连宿主机时填 host.docker.internal
📦 Redis
用于缓存、验证码与定时任务共享状态。向导只测试连接。
连 compose 的 redis 时请留空（它只创建 default 用户）
🔐 安全
推荐格式为 openssl rand -hex 32 生成的 64 位十六进制；留空保存时自动生成，更换后所有已登录令牌失效
用于落库敏感数据加密，留空则沿用现有值/派生
用于生成 PROD_CORS_ORIGINS、ALLOWED_HOSTS、 OAUTH_ALLOWED_HOSTS，以及前端生产 API / WebSocket 地址。 也可填写完整 URL（https://admin.example.com）。
留空沿用现有值；直连公网部署时不建议放宽
🖥️ 前端与小程序
写入 Web 与小程序 env 的 VITE_APP_TITLE
API 与 WebSocket 地址由运行环境 + 后端端口 + 生产域名自动推导，无需手填。
🐳 Docker 部署
账号、口令、密钥与后端配置保持一致；文件不存在时从 .env.example 生成
